# 購入部品の一覧（初心者向け）

最終確認日: 2026-11-17

小型の8自由度四足（派生機体 `mini`: 胴体 96 × 62 mm、上腿 40 mm、下腿 44 mm、サーボ MG90S × 8、電池なし）を
1台作るために買う物の一覧です。**実機はまだ製作していません**。部品の数量は設計から出した値で、
組み立てて確かめたものではありません。

- 数量の根拠: `artifacts/mini/design_report.json` の `bom`、[manufacturing.md](manufacturing.md)、
  [hardware-spec.md](hardware-spec.md)、[esp32-deployment.md](esp32-deployment.md)。
- 価格は **2026-11-17 に Web で見た表示価格**（税込みの表示をそのまま書いています）。価格・在庫・送料は変わります。買う前に各ページで確かめてください。
- 3D プリンタ（Bambu Lab A1 mini の予定）の代金は、この一覧の合計に含めていません。
- 足先は設計上 TPU ですが、この一覧では **PLA で印刷して滑り止めシートを貼る** 前提です。
- 電源は最初は電池を使わず、**5V の電源（スマホの充電器か AC アダプタ）から USB / DC ジャックで給電**します。

## 3. 買うとき・使うときの注意

### サーボ（安い互換品の当たり外れ）

- 10個入り ¥3,099 は1個あたり約 ¥310 で、秋月の正規品（1個 ¥1,540 https://akizukidenshi.com/catalog/g/g113227/ ）の5分の1です。
  レビューには「一部のギアが樹脂」「10個中1〜2個動かない」とあります。8個使うので、2個は予備として残します。
- 届いたら、組み立てる前に1個ずつ ESP32 につないで、端から端まで動くか、異音がしないかを確かめます。
- 設計の強度計算は金属ギアの MG90S（失速トルクなどはデータシートの値）を前提にしています。樹脂ギアの個体で同じ力が出るかは未確認です。
- SG90 版も設計の判定は通りました（依頼者との検討での試算）。ただし Amazon の10個セットでは MG90S のほうが安いことがあり、
  樹脂ギアの SG90 は欠けやすいので、MG90S にしました。

### 電源（スマホの充電器で代用する場合）

- **充電器の本体に書かれた出力（5V で何 A か）を確かめてください。** 小さい字で「OUTPUT 5V⎓3A」のように書いてあります。
- **3A 未満なら**、サーボ8個を同時に動かすと電流が足りない可能性が高いです。足りないと ESP32 が再起動したり、サーボが震えたりします。
  この場合は秋月の AC アダプタ 5V 4A（¥1,650）と DC ジャック（¥300）を買うのを勧めます。
- **3A 以上でも、足りない可能性はあります。** サーボ8個が実際にどれだけ電流を使うかは実測していません。
- USB-PD などで 9V や 12V を出す充電器もあります。**サーボにつなぐのは 5V だけ**にしてください（MG90S の動作電圧は 4.8〜6.6 V）。
- DC ジャックのキットの定格は **3A** で、AC アダプタの 4A より小さいです。アダプタが 4A 出せても、DC ジャックに流してよいのは 3A までです。
  サーボを一度にたくさん大きく動かさない、など使い方で抑える必要があります（実測はしていません）。
- **GND（マイナス、黒や茶色の線）を共通にしてください。** サーボの電源を ESP32 とは別の電源から取る場合も、
  電源の GND と ESP32 の GND をつながないと、サーボが信号を正しく受け取れません。
- サーボの電源を ESP32 ボードの 5V ピン経由で取るのは避けてください。ボード上の配線やパソコンの USB ポートに大きな電流が流れます。
  配線の詳しい注意は [esp32-deployment.md](esp32-deployment.md) §8 にあります。

### USB ケーブル

- **データ通信に対応したケーブル**を使ってください。充電専用のケーブルでは、ESP32 にプログラムを書き込めません。
  パソコンにつないでもボードが認識されないときは、まずケーブルを疑います。
- ボード側の端子（USB-C か micro-B か）は、ボードの型番が分かってから確かめてください（未確認）。

### ブレッドボード

- ESP32-S3 の開発ボードは幅が広く、ブレッドボード1枚に挿すと片側の列にしか線を挿せなくなることがあります。
  **2枚を並べて、ボードの左右のピンをそれぞれの板に挿す**と楽です。
- サーボの線の先はメス（穴）です。ブレッドボードとつなぐには、オス–オスのジャンパー線を差し込みます。

### ネジ

- 使うネジは2種類です（`design_report.json` の `bom` より）。
  - **M2×10 の六角穴付きボルト: 2本**（胴体の上下を留める。胴体の下側の穴にねじ込む）
  - **M2×6 のタッピングネジ: 16本**（サーボのホーンと脚の部品を留める。1関節に2本 × 8関節）
- 手元のネジが **M2（太さ 2 mm）でない場合や、長さが合わない場合は買い足しが要ります**。
  太すぎると穴（直径 2.2 mm）に入らず、長すぎると反対側に突き抜けたりサーボに当たったりします。短すぎると留まりません。
- サーボの出力軸にホーンや脚を留めるネジは、サーボに付いてくるものを使う想定です。
- PLA にタッピングネジを何度も締め直すと、ねじ山が削れて緩みます。締めすぎないでください（保持力は未検証）。
